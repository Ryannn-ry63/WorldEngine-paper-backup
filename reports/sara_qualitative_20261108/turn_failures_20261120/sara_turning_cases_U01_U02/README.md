# U01 / U02：转弯时转向不足

U01 为优先候选；U02 为弱备选。这次用容易理解的“该转弯时车头转向不足”描述，不讨论停车动机或复杂的时序机制，也不根据四秒片段断言最终驶入错误出口。

绿色虚线是原始 nuPlan 数据库中同一 lidar token 起始的0–4秒人类轨迹，用于确认转弯任务背景。其初始位置与闭环输入匹配；它不是闭环反事实模型或唯一最优轨迹。模型使用各自真实执行的轨迹和物体，不对齐到人类终点、不拉伸时间、不修正位置。

## 两例的证据强度

### U01

优先看这一例。原始记录是左转，Base 四秒内车头左转约17.5°，SARA 仅约0.2°。两边行程约4.3m和3.7m；在相同行程约3.7m处比较，车头方向仍相差约17.5°，所以区别不只是前进速度。Base 也没有在四秒内完成整个左转，不能写成 Base 已完整成功通过。

### U02

弱备选。Base 右转约39.6°，SARA 约22.0°，但相同行程处只差约5.3°，相当部分差异与行程长短有关。可看作右转不足的参考，不建议作为证明独立转向缺陷的主例。

U01 原始记录四秒车头左转约68.5°，Base17.5°、SARA0.2°；U02 原始记录右转约93.6°，Base39.6°、SARA22.0°。两种模型都没有追上原始记录的完整转弯进度，因此不把 Base 称为完整通过的成功模型。对等行程的方向对比比单看终点姿态更能区分“走得短”与“转得少”。

航向方向以初始车头方向为零，左转为正、右转为负。数据保留九个0.5秒采样。相同行程插值仅用于数值比较和诊断曲线，实际轨迹图仍使用原始位置，没有对位置插值或平滑。

两例 Base/SARA 的 NC/DAC/TTC/comfort 都为1。U01 PDM约0.794→0.736；U02约0.871→0.846。这里侧重可见的转向表现，不将总分下降单独当作转向错误的证明。当前记录不足以判断是否源于意图输入、感知、生成器或选择器，不能作单一因果归因。

## 独立改图

```bash
pip install -r requirements.txt
python plot_cases.py --gif
python plot_cases.py --cases 1 --formats png pdf svg --output edited_figures
```

修改plot_cases.py的STYLE可改字体/颜色/线宽/分辨率/视窗，TIMES默认[2.,4.]。data内包含地图、两边实际轨迹、原始参考轨迹、时间和来源哈希，不需要原实验目录、nuPlan、模型或GPU。figures内有PNG/PDF/SVG、GIF以及速度/航向随时间/航向随行程三组曲线；camera是原始闭环前视画面。

同一正式Base和V3 online rare-log seed0 epoch2，模式R。原始metadata SHA256再次复核，初始物体和时间戳匹配。所有结论限于四秒记录，不外推最终转弯结果。
