# 新候选 35–39：按 2 秒 / 4 秒比较

这批用于挑图，不是独立评测集。优先看 35、36；37 是更直观的直路推进对照。38 补充道路边缘的差异，39 是有其他车辆的备选。

打开 `index.html` 可以看五例截图、前视画面和 GIF。每张主图上排 Base、下排 SARA，左列 2 秒、右列 4 秒。四个子图共用初始坐标系和同一视窗。虚线车框是初始自车位置；黑方块是初始后轴；实线为执行至当前时刻的轨迹。没有箭头，没有未来轨迹外推。灰色车辆是该模型闭环记录在对应时刻的其他车辆，两边交通会分别演化。

## 推荐顺序与观察

| 编号 | 类型 | 2–4 秒 Base / SARA 行驶距离 | 可以展示的差异 |
|---|---|---|---|
| 35 | 右转入口继续推进 | 0.45 / 9.08 米 | Base 在入口缓慢挪动；SARA 进入右转。最接近原 24 的主题，但没有回退。 |
| 36 | 弯道中持续行驶 | 3.35 / 10.90 米 | 2 秒时两者接近，之后 Base 减速至近停，SARA 继续沿弯道走。 |
| 37 | 直路推进 | 3.81 / 14.27 米 | 前两秒相近，后两秒 Base 逐渐近停，SARA 持续行驶；环境比较简单。 |
| 38 | 弯道边缘与推进 | 5.35 / 10.74 米 | Base 更贴近道路边缘并明显减速，SARA 沿弯道继续行驶。 |
| 39 | 有周边车辆的路口驶出 | 1.85 / 16.19 米 | Base 驶出一点后近停，SARA 继续驶出；差异明显，但 SARA 后段提速较多，列为备选。 |

这些距离是 2–4 秒间四段真实位移的欧氏长度之和；不是相对起点的 x，也不是 benchmark EP。逐例数值见 `summary.csv`。

35、36、37、39 主要对应进度反馈（EP）；两种方法的 NC/DAC/TTC 都通过。38 还对应正式 DAC 的 0→1。两种方法都在闭环中评测，不应将 Base 描述为“本次只做开环”。这里只展示在线训练前后闭环行为差异，不能仅凭例图归因于某一个奖励项。

## 已核对与具体局限

- 这五例的两种方法，九个采样位置之间的八段位移，投影到相邻车头中间方向后**全部为正**，累计回退均为 0。35 的 Base 最小一步约 6.6 厘米；36 的 Base 最小一步约 2.6 厘米。它们是缓慢前移，不是倒车。
- 两种方法起始自车、起始其他车辆、时间戳一致；记录间隔均为 0.5 秒；原 metadata 的 SHA256 已重新核对。完整记录保存在 data/，不是只导出两帧。
- 看过原始前视 0/2/4 秒画面。35 的近处轨迹前方没有记录到阻挡车辆；这不能证明模型没有错误检测到障碍物，也不能解释内部停车原因。没有完整候选预测/检测输出，不宣称“因误检而停车”。
- 35 在路口转向，几何车道覆盖检查末帧约 75.6%，有约 1.6% 的普通对向车道最大车身重叠；正式 DAC 通过。它的转弯轮廓并非完全落在所匹配车道多边形内，需结合图片选择，不能写成完美车道保持。
- 36/37 的 SARA 同向车道覆盖最低约 97.7%/100%，未检出普通对向车道车身重叠；39 最低约 90.7%，最大普通对向车道重叠约 3.2%。这是地图几何辅助检查，不是正式指标。
- 38 的 Base 正式 DAC=0，但可视的越界量很小，末帧同向车道覆盖仍约 98.9%；不宜夸大为严重冲出道路。两边均未与记录的 route block 列表匹配到对应车道组，所以此例不作路线正确性的证据。SARA 道路同向覆盖为 100%。
- 39 的 SARA 末速约 9.57 m/s（34.5 km/h），Base 约 0.22 m/s。SARA 末帧与最近旁车多边形间隔约 1.16 米；图中有邻车/停放车辆，不能宣称它是最保守的例子。
- 所有结论限于已记录的 4 秒。未重新运行更长闭环，不能保证 4 秒后无风险。图中不补画不存在的后续轨迹。

## 修改图片

不依赖仿真器、地图 SDK、GPU 或原始实验目录。将整个目录复制到电脑上：

```bash
python -m pip install -r requirements.txt
python plot_cases.py --gif
```

只画一个：

```bash
python plot_cases.py --cases 36 --gif
```

改 `plot_cases.py` 顶部的 `STYLE`：配色、字体、字号、dpi、画布大小、是否显示初始车框等。`TIMES=[2.,4.]` 是截图时刻。`STYLE['case_overrides']` 可指定逐例 xlim/ylim，两模型和两个时刻共同使用，避免坐标视窗不一致。进一步改布局看 `snapshots()`，改车辆样式看 `panel()`。

默认输出 PNG/PDF/SVG 和 GIF 到 `figures/`。PDF/SVG 可用于论文和矢量编辑。GIF 每帧是真实 0.5 秒采样，末帧停留 1.5 秒以便查看，不作补间。不要用裁剪或篡改数据掩盖已知问题。

## 来源与筛选

数据来自同一正式 R 评测：Base 与 V3 online rarelog seed0 epoch2。可用 280 对场景中，预筛要求 SARA NC/DAC/TTC 全通过、PDM 提升至少 0.06、SARA 回退≤3厘米且 Base 回退≤5厘米；排除已展示编号后得到 41 个候选。随后检查地图方向、2/4秒截图和前视画面；最终五例进一步要求两边每一步均向前。一个曾考虑的直路例 `c28c7b29e80059d2` 因 Base 仍有约 3.6 厘米回退未入选。

源 metadata 路径、SHA256、完整逐帧车道检查、R/NR 正式分数均在 `data/case_*.json`。阅读这些 JSON 不需要原始文件；路径仅供服务器溯源。`verification.json` 汇总核对结果。本包未改动原来的 12/22/23/24/30 图片、ZIP 或论文。
