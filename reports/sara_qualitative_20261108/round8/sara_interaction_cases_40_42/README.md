# 交互类候选 40–42：2 秒 / 4 秒对照

这轮优先看 **40（右转车流冲突）**。41、42 是路口车流跟随的备选，仍属于跟车安全这个大类，不把它们说成完全不同的机制。三例均可从周边车辆的相对位置指出 Base 的具体问题，不依靠“Base 不明原因停车”的叙述。

## 40：右转车流中的冲突避让

主图 `case_40_2s_4s` 是 **NR（非反应式交通）**。两种方法同为 NR：Base 不断接近橙色车辆，2 秒时车身间隔约 0.43 米，2.5 秒采样起已有车身重叠，4 秒时仍重叠；SARA 先减速，再缓慢前行，2 秒/4 秒与同一车辆间隔约 4.75/11.59 米。正式 NC/TTC 均为 Base 0 → SARA 1。

`case_40_R_2s_4s` 是同场景的 **R（反应式交通）**补充。R 中 Base 没有发生采样车身重叠，但末帧与该车间隔约 0.44 米，TTC=0；SARA 对应间隔约 7.28 米，TTC=1。两种方法在 R 的 NC 都是 1。不要把 R 的图片配上 NR 的碰撞指标，也不要用 R 的 Base 对比 NR 的 SARA。

局限：四秒内 SARA 主要展示转弯前的减速和保持间距，还没有展示完成右转。其进度低于 Base（NR EP 约 0.43，R EP 约 0.46），因此应解释为安全与进度的取舍，不能写成“既完成转弯又全面更快”。交通中还有其他近邻车辆；NR SARA 的最小全体车身间隔约 0.67 米，不能将与橙车的 11.59 米误写成对所有车辆的最小间隔。

## 41：路口排队时避免追撞（R）

前方橙车在路口排队。Base 从低速起步后持续加速，2 秒仍与橙车相隔约 6.15 米，到 3.5 秒采样已发生车身重叠；SARA 保持低速、保留间距，4 秒仍与该车相隔约 7.06 米。正式 NC/TTC：Base 0 → SARA 1。

局限：它属于排队跟车安全，与最早的 1 是同一大类。图像可以指出 Base 接近前车并发生碰撞，却不能仅由轨迹判断内部感知或规划的具体错误。前视画面里的信号灯仅作场景背景，不把此例标为已核实的闯红灯违规。

## 42：路口车流起步时保持间距（R）

前车在路口附近前进，Base 的追近速度明显过大：2 秒车身间隔约 3.69 米，3.5 秒采样起发生重叠；SARA 跟随前进后减速，4 秒与同一车间隔约 5.69 米。正式 NC/TTC：Base 0 → SARA 1。

局限：仍是跟车交互，作为 41 的另一个场景供挑选，不主张两者必须同时入论文。SARA 在末段减速，示例仅支持四秒内安全间距改善。

## 图与检查

- 主图上排 Base、下排 SARA；左列 2 秒、右列 4 秒。地图、自车、其他车辆固定在同一初始坐标系，四个子图使用相同视窗。所有轨迹点是真实记录，0.5 秒间隔；没有箭头、外推或补间。
- 橙色表示同一辆交互车辆，使用与 `gt_boxes` 一一对应的 `anns.track_tokens` 跨时刻、跨模型匹配。其余车辆为灰色。并非每帧任意挑最近的一辆；目标车辆的逐帧索引、间隔和重叠面积均在 JSON 中。
- 三个场景、四组比较的两种模型均无采样后向位移。SARA 的全部九帧均未检出自车与记录其他物体多边形重叠，也未检出普通对向车道车身重叠。同向车道覆盖约为 100%。这些是辅助几何检查，不能替代正式评测或证明四秒之外的安全。
- 原始 metadata SHA256 已重新核对；每组的起始周边车辆和时间戳一致。两种方法都执行闭环评测；不能将 Base 本次评测称为开环。
- 此轮排除了：35 一类进入对向车道的例子；无明确交互的推进差异；会回退的候选；以及一个 NR 施工区例子——它虽 NC=1，但 SARA 的记录里仍与另一车辆发生了几何重叠。没有用分数通过掩盖画面问题。
- 现有数据无法直接定位 Base 内部为什么选择危险轨迹。这些例子说明行为及奖励项差异，不证明单个奖励项的因果贡献。

## 文件与重画

`data/` 含完整九帧轨迹、周围车辆、地图、R/NR 指标与溯源信息；`camera/` 是原始前视 0/2/4 秒拼图；`figures/` 含 PNG、PDF、SVG 与完整 GIF。`summary.csv`、`verification.json` 是数值汇总与检查结果。

```bash
python -m pip install -r requirements.txt
python plot_cases.py --gif
```

只重画主案例 40：`python plot_cases.py --cases 40 --gif`。默认不传 `--cases` 时会同时重画 R 补充版本。

修改 `plot_cases.py` 顶部 `STYLE` 调整字号、颜色、画布和视窗；`TIMES=[2.,4.]` 控制截图时刻；`highlight_actor=False` 可取消橙色高亮。PDF/SVG 可用于论文编辑。程序不依赖原始服务器、仿真器、地图 SDK 或 GPU。
