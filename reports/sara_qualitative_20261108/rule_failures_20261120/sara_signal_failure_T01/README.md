# T01：信号遵守失败

这是一个场景的两种交通模式：R 为主版本、NR 为补充。没有把两个模式当成两个独立场景。它不属于“推进过慢”，而是在红灯期间未在停止区前停住。建议先看 index.html 和相机原图，再看信号/位置诊断图。

## 为什么它独立于碰撞、DAC

两种模式中，两边正式 NC/DAC/TTC 都为1，SARA PDM=1，而 Base 约0.78。自车没有因这个指标组合而体现出红灯停车行为。可以讨论：当前闭环评分中的碰撞、道路合规、推进收益不足以替代显式规则约束。不能据此推断所有成功例子都有规则问题，也不能直接称作已证实的 reward hacking。

这不是“Base 过于保守、SARA 更有效率”的成功图。Base 在红灯期间留在停止区前；SARA 的更多推进伴随信号约束问题。仍不能解释两种模型的内部停车动机。

## 证据链

- 同一场景 token：12f2dccfb88957f9；Base 与 SARA checkpoint 与此前图一致。每个模式内部初始位姿、物体和时间戳匹配，原始元数据 SHA256 复核。
- 初始自车后轴位于地图 lane 48529 内，方向与该车道一致。
- 地图 stop_polygons 的 48528 对应该进路，lane connector 的 traffic_light_stop_line_fids 明确引用它。连接段 52823、52956、52974 从该进路分别进入不同方向；涉及当前自车直行的连接段也在其中，避免只看邻向灯。
- 原始 nuPlan 数据库按同一 lidar token 和时间戳查询，三个信号在0.5、1、…、4秒全部为 red。两种模型原始 metadata 中相同三个 ID 也全部记录为红灯。t=0 这些 ID 未记录，保留为 unknown，不外推灯色。
- 使用原始世界位姿、真实车身尺寸计算车头相对于停止区下游边界的投影。在两种模式里，SARA 车头都在3.0秒之前尚未越过，到3.5秒已经越过。四秒时 Base 始终在该边界之前，SARA 已超过。
- 所画粗红线使用地图停止区多边形的下游边界，仅作保守几何核对。停止区有面积，不能把其中某条边直接当成图像中白色标线的精确描摹，也不能根据0.5秒采样给出精确违规发生时间。

SARA 实际上也在减速，并非持续加速或完全没有反应。更准确的观察是“减速仍不足以在受控停止区前停住”；不声称模型有意闯红灯。

## 筛选过程与局限

以正式288对R、288对NR清单为范围，缺失元数据跳过，先查有红灯信息且 SARA 比 Base 多推进的片段，得到117个模式/场景对。初步仅看连接段多边形会产生旁向灯和重叠区域的假阳性，进一步核对自车初始车道、停止区和对应受控连接段后，留下这个场景的R/NR两个版本。因此只提供一个证据完整的例子，不凑多个弱例。

同一场景的两模式复现不能当作多随机种子统计。没有重跑模型或逐候选反事实干预，未恢复完整候选与评分；不能分配感知、生成器、选择器的因果责任。该例同时涉及 SARA 的实际直行方向与原始路线右转意图可能不一致，但这里的红灯核对覆盖同一进路的三个受控方向，不仅依赖路线参考来判定。

Base近停后有小幅回退，R累计约0.45m、NR约0.43m，均原样保留；SARA没有采样回退。规则结论依赖是否在红灯期间越过停止区，不依赖Base这些细小近停位移。

所有结论限于0–4秒记录和离散采样。所谓“信号遵守失败”是相对于仿真/地图记录的红灯与停止区定义，不作现实道路执法责任认定。图中的红色区域是信号停止区，不是DAC意义的非可行驶区域。

## 文件与改图

- figures：2/4秒对照、3/3.5/4秒关键帧、GIF、诊断曲线，均有PNG/PDF/SVG。
- camera：原始前视0/2/4秒对照以及两模型4秒完整前视图。
- data：地图停止区、边界、原始轨迹与物体、对应信号和数据库查询结果、正式分项、来源哈希。
- verification.json：核对结果和两个模式对应关系。

```bash
pip install -r requirements.txt

```

编号1是R，编号2是NR。编辑plot_cases.py的STYLE改字体、配色和画布，TIMES默认[2.,4.]，关键帧在data的critical_times中设置。文件名仍沿用critical_2s_4s后缀，请以面板标注的3/3.5/4秒为准。只用numpy、matplotlib、pillow即可独立重画，不需要模型权重、原始数据库、nuPlan或GPU。原始相机画面不由绘图脚本重生成。

诊断图的正距离表示车头越过地图停止区的下游边界，负距离表示仍在之前；不等于与人行横道或路口中心的距离。右图来自原始数据库的信号记录，未观察时显示Not recorded。
