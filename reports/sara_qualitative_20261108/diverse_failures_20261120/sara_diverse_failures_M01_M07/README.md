# 多类型失败 M01–M07

这批补充上一组 DAC 退化案例。建议优先 M01/M03/M06；M02/M04 为交互备选；M05 混合因素多；M07 动机不明，仅供挑选。

## 行为与分析方向

| 类别 | 案例 | 能直接看到的变化 |
|---|---|---|
| 加速进入冲突 | M01/M02 | Base 等待或转向减速，SARA 加速后 NC/TTC 下降 |
| 近距离通过/横向间隙 | M03/M04 | 更快通过，TTC 下降；M03 采样无重叠，M04 有重叠，两者不能混称 |
| 早减速与侧后方交互 | M05 | 自车先降到近停，随后右后侧车辆发生接触；还含回退 |
| 推进不足、恢复迟缓 | M06/M07 | Base 恢复或继续前进，SARA 继续减速/近停 |

可用“对不同交互状态的速度与时机判断仍不稳定”作为工作假设，但不要仅凭这些例子宣称已经证明模型内部推理机制、候选覆盖不足或奖励导致了过度激进/保守。上一组 DAC 场景表现为更多推进，本组同时有过度推进和推进不足，不能总结成 SARA 全局速度更快。

M01 与正文跟车追撞相比多了侧向车辆运动；M02 同时有路线差异，不能只讨论速度；M03 没有采样接触，适合讨论风险余量。M06 更接近“前车已经离开而未及时跟上”，相比单纯截取一辆停着的车，证据较清楚。M07 仍不能排除停车有合理理由，保留为低优先级备选，不能写“无故停车”或仅依据可见灯色确定完整路权。

## 来源与检查

同一正式 Base 与 V3 online rare-log seed0 epoch2；每例 Base/SARA 时间戳、初始位姿和初始其他物体匹配，原始元数据 SHA256 再次核对。全部保留各自闭环中实际记录的物体与位姿。M01–M05 为 NR，M06/M07 为 R，不能把不同模式当成完全相同的交通配置；每张图内模式相同。M02 与此前 F04 使用同一场景 token 但模式为 NR：它在 R 与 NR 下的交通/结果不同，必须连同模式解释。

本轮按 NC/TTC 下降和显著 EP 下降筛查 31 个模式/场景对，其中 30 对可读，选出七例。这是定性挑选，不能用 7/30 估计各类型频率。正式结果里没有 comfort 从 1 降至 0 的样本，因此速度模长变化不称为正式 comfort 失败。

全部七例正式 DAC 两边都为 1；M01/M02/M05 的正式 NC Base=1、SARA=0；M03/M04 的正式 TTC Base=1、SARA=0，而 NC 都为1；M06/M07 两边 NC/DAC/TTC 都为1，主要差距是 EP。具体见 summary.csv。

交互车辆用过滤后的 `anns.track_tokens` 对齐 `gt_boxes`，逐帧检查数组长度。没用未过滤的 `original_track_tokens`。M01–M05 标出接触或最近接近的同一辆目标车；M06 标出起步离开的前车；M07 不突出某辆车，诊断间隙仅对应记录中选定对象，不当成停车原因证据。

NC 的定义是 no-at-fault collision。M04 虽 NC=1，但3–3.5秒存在实际记录车身重叠，不能称“仅险些碰撞”。M03 最大采样重叠为0，最近车身间隙约0.11米，可以描述近距离通过，仍不能保证采样间完全无接触。诊断图的 gap=0 本身不能区分刚好相切与穿透，请同时看 verification.json 的 overlap_m2 和关键帧。

M05 有约0.87米累计近停回退，M07 有约0.28米，都是原始记录保留；不能把 M05 单独归因于早刹车导致追尾。侧后方目标初始在自车右后方，随后接近，因此称“侧后方接触”，不直接指认责任。M05 附3.5秒多视角相机，前视图无法看全接触区域。

没有重跑候选推理或反事实干预；没有恢复已删除的全量候选/评分，因此不分配“生成器还是选择器”的因果责任。所有观察限于0–4秒、0.5秒采样。

## 文件与改图

打开 `index.html` 浏览图、诊断曲线、GIF 和关键帧。`figures` 有 PNG/PDF/SVG 与 GIF；`camera` 是原始评测前视图及 M05 多视角图；`data` 包含独立绘图数据、正式指标、物体身份和来源。无需原实验目录、模型权重、地图数据库、nuPlan 或 GPU。

```bash
pip install -r requirements.txt
python plot_cases.py --gif
python plot_cases.py --cases 1 3 6 --formats png pdf svg --output edited_figures
```

修改 `plot_cases.py` 的 STYLE 可改字体、颜色、分辨率、视窗等，TIMES 默认 `[2.,4.]`。`highlight_actor` 控制橙色目标车。关键帧使用 data 内 `critical_times`，默认2/3/3.5/4秒；标注清晰，但文件名沿用 `_critical_2s_4s` 后缀，请以面板时间为准。所有面板共用初始坐标和比例，没有箭头或轨迹修正。前视画面不由这份 BEV 绘图脚本重新生成。

## 逐例

## M01 · 侧向车辆尚未通过就继续加速（NR）

**碰撞 · 优先。** Base NC/TTC=1；SARA NC/TTC=0，2.5–3.5s 与橙色车辆出现采样车身重叠。Base 先等再起步，SARA 提前加速。 实际四秒行程 4.1→14.1m；2 秒速度 0.4→3.3m/s。

## M02 · 路口加速后与卡车发生冲突（NR）

**碰撞 · 备选。** Base 按右转方向减速，SARA 加速并更趋直行，3.5s 起与橙色卡车重叠，NC/TTC 1→0。此例同时有路线差异，不能只归因速度。 实际四秒行程 13.2→25.7m；2 秒速度 5.0→7.1m/s。

## M03 · 遇到对向来车仍加速通过（NR）

**危险接近 · 优先。** 两边 NC/DAC=1，TTC 1→0。SARA 在减速后重新加速，3s 左右与目标车最近间隙约 0.11m；未检出离散采样车身重叠。 实际四秒行程 10.1→29.2m；2 秒速度 1.4→7.9m/s。

## M04 · 横向来车前继续加速穿过路口（NR）

**危险接近/接触 · 备选。** 正式 NC/DAC 两边均为 1，TTC 1→0；SARA 在 3–3.5s 有几何车身重叠，不能称为无接触，也不能改写为正式有责碰撞。 实际四秒行程 4.2→21.6m；2 秒速度 0.1→5.4m/s。

## M05 · 较早急减速后，右后侧仍发生接触（NR）

**减速与侧后方交互 · 混合因素备选。** Base NC=1，SARA NC=0。SARA 更早接近停车，随后右后侧车辆接近并在 3.5s 出现重叠。SARA 另有约 0.87m 累计回退，不能把失败全归因于减速。 实际四秒行程 7.9→5.6m；2 秒速度 1.7→0.3m/s。

## M06 · 前车已起步，SARA 仍降到近停（R）

**推进下降 · 优先。** 两边 NC/DAC/TTC=1。Base 跟随前车加速，SARA 继续降到近停，与前车间隙从约 8.2m 扩到约 17.9m，EP 1→约0.19。 实际四秒行程 9.9→1.7m；2 秒速度 1.9→0.3m/s。

## M07 · 接近路口时过早停下，推进明显落后（R）

**推进下降 · 备选，解释较弱。** 两边 NC/DAC/TTC=1；Base 四秒推进约27m，SARA 约4m，EP 1→约0.19。SARA 有约0.28m 回退；其停车动机和完整路权无法仅凭画面确认。 实际四秒行程 27.3→3.8m；2 秒速度 6.7→0.4m/s。
