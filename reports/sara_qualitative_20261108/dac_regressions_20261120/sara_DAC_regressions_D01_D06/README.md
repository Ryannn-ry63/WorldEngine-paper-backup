# DAC 下降与更积极推进：D01–D06

先看 `index.html`，建议优先 D02、D04，D01 是此前 F05 参照。D03、D05、D06 为备选，幅度较小。所有案例使用与正文相同的 Base 和 V3 online rare-log seed0 epoch2 checkpoint。

## 筛选依据与解释

每例在自己的同一 R 或 NR 模式内均为 Base DAC=1、SARA DAC=0，同时 SARA 行程更长。R 全部 13 个 DAC 退化样本都行程更长、2 秒速度更高；NR 的 15 个分别为 14 个和 12 个，见 `conditioned_summary.json`。这组现象支持“推进与道路边界余量之间的取舍”作为讨论方向；不能凭条件筛选后的子集推出 SARA 全局更激进，或认定在线奖励、速度偏高就是越界的唯一根因。没有统计检验或重跑。

大部分新例子是车身角部或贴边越界，幅度比 D01 小，已给出实际尺度，不能写成整车冲出道路。D05 最大问题在 3 秒，4 秒减轻，因此必须结合动画。D04 仅 NR 满足该退化条件；相同 token 的 R 模式两边都 DAC=0，不作为本次的比较。

## 图与辅助几何

总览共用固定初始坐标、视窗、比例：上排 Base，下排 SARA，左 2s，右 4s。显示的都是实际执行位置前缀，没有平滑或位置修正。深色边界是局部普通车道、连接段、路口、停车区多边形的并集；洋红色是自车车身超出该并集的部分。车身和地图均保持实际米制尺度。

辅助并集不等于完全重建正式 PDM 的 drivable map（后者还收集 roadblock 等对象并检查车身角点），因此曲线/边界只是定位问题的辅助量，正式 DAC 一律取原 accepted 结果，不能把两者的几何数值混为同一个评测。D01 明显越出通道；新例子多数是更细的道路边缘问题。

诊断图左列是速度模长、中列是辅助越界面积，右列是 SARA 最大越界时刻的 8m×8m 局部视图。局部视图只是缩小视窗，仍使用初始坐标和原始几何；不与 Base 的不同位置作重叠拼接。注意每幅总览的速度标注与实际时刻。

## 编辑与复现

```bash
pip install -r requirements.txt
python plot_cases.py --gif
python plot_cases.py --cases 2 4 --formats png pdf svg --output edited_figures
```

直接编辑 `plot_cases.py`：`STYLE` 改字体、配色、线宽、分辨率和画布；`TIMES=[2.,4.]` 可改为原始 0、0.5、…、4s 采样；`case_overrides` 可对某个数字编号固定所有面板的 xlim/ylim。例如看 D05 的中间过程可把 `TIMES` 改为 `[2.,3.,4.]` 并相应增大画布宽度。无需原实验目录、模型、nuPlan 数据库、GPU 或 Shapely。

- `data`：独立绘图数据，含原始记录位置、地图、每时刻物体、超出并集的车身片段与正式分项。
- `figures`：PNG/PDF/SVG、GIF、诊断图。
- `camera`：原始闭环前视图 0/2/4s，不由绘图脚本重生成。
- `verification.json`：原始数据 SHA256 复核、时间戳/初始物体检查、模式与几何诊断。
- `summary.csv`：两边正式 DAC、PDM、行程与速度。

所有观察限于四秒、0.5s 采样。个例可以支持描述性行为分析，不能直接证明候选不足、感知漏检、训练奖励偏置或选择器内部意图。

## 各例

### D01 · 柱廊入口继续推进后越界（R）

原 F05，保留参照；越界最明显。 四秒行程 Base 3.8 m → SARA 10.7 m；2 秒速度 0.4 → 3.1 m/s；4 秒速度 0.2 → 1.8 m/s。辅助几何首次检出越界约 3 s，最大角点超出约 2.05 m。

### D02 · 左转后继续加速，压出道路边缘（R）

Base 后半段减速，SARA 持续加速；道路越界约 0.20 m，局部细节较小。 四秒行程 Base 13.7 m → SARA 23.2 m；2 秒速度 4.4 → 5.8 m/s；4 秒速度 0.1 → 7.6 m/s。辅助几何首次检出越界约 3.5 s，最大角点超出约 0.20 m。

### D03 · 路沿附近收速不足，车身越界增加（R）

Base 停在前方，SARA 继续推进；采样最大角点越界约 0.34 m。 四秒行程 Base 11.8 m → SARA 18.3 m；2 秒速度 2.4 → 4.6 m/s；4 秒速度 0.0 → 1.1 m/s。辅助几何首次检出越界约 2 s，最大角点超出约 0.34 m。

### D04 · 沿路边继续前行，右侧车身越出（NR）

此例仅 NR 满足 DAC 1→0；R 两边均 DAC=0。不能跨模式混用。 四秒行程 Base 12.6 m → SARA 18.4 m；2 秒速度 1.4 → 3.6 m/s；4 秒速度 0.3 → 3.5 m/s。辅助几何首次检出越界约 1 s，最大角点超出约 0.52 m。

### D05 · 出口弯道保持较高速度，中段越界（R）

越界主要发生在 2.5–3.5 秒，4 秒已减轻；附 3 秒关键时刻。 四秒行程 Base 22.2 m → SARA 28.9 m；2 秒速度 5.9 → 7.4 m/s；4 秒速度 3.5 → 7.5 m/s。辅助几何首次检出越界约 2 s，最大角点超出约 0.16 m。

### D06 · 减速较晚，多走后贴出路边（R）

简单路段，转向差异细；展示减速时机与边缘余量的备选。 四秒行程 Base 9.7 m → SARA 13.4 m；2 秒速度 1.1 → 3.3 m/s；4 秒速度 0.3 → 0.1 m/s。辅助几何首次检出越界约 3 s，最大角点超出约 0.23 m。
