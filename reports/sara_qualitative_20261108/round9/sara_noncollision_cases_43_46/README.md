# 43–46：非碰撞候选及可编辑绘图

先看 `index.html`，或打开 `figures` 中的图片/GIF。43 是左转出口推进，44 是宽路口左转，45 是右弯推进，46 是道路边缘车道保持。这些是供进一步挑选的候选，不是四个都已确认适合论文的成功案例。

## 修改图片

解压后在此目录运行：

```bash
pip install -r requirements.txt
python plot_cases.py --gif
python plot_cases.py --cases 43 46 --formats png pdf svg --output edited_figures
```

直接修改 `plot_cases.py`：

- `STYLE`：字体、颜色、线宽、分辨率、画布尺寸。
- `TIMES = [2., 4.]`：截图时刻。只有原始 0、0.5、…、4 秒采样可选，不会插值。
- `STYLE['case_overrides']`：例如 `{'43': {'xlim': [-8, 30], 'ylim': [-10, 28]}}`。同一例所有模型和时刻始终共用相同视窗。
- `STYLE['show_title'] = False` 可关闭大标题；`panel()` 可改面板文字和图例表现。

`data/case_*.json` 已包含独立绘图所需的地图、车身、轨迹和时间戳，不需要原实验目录、nuPlan 数据、模型权重或 GPU。PDF/SVG 用于论文，SVG 保留文字元素。相机拼图来自原始评测渲染，不由这份 BEV 脚本重新生成。

## 文件与来源

- `figures`：2s/4s PNG、PDF、SVG，0–4s GIF。
- `camera`：原始前视画面 0/2/4 秒对照。
- `summary.csv`：正式评测分项、实际行程、2s/4s 速度。
- `verification.json`：元数据校验、非回退与几何检查。
- `data` 内 `provenance`：原始元数据位置和 SHA256；`metrics`：正式评测结果；`direction_audit`：辅助地图几何诊断；`motion_screen`：筛查数据。

Base 来自 `selector_ab_scale_nodes8_perception50_20261010/evaluation/base/closed_R`；SARA 来自 `selector_v3_online_rarelog_20261017_mapfix_v2_s0/evaluation/v3_online_rarelog_s0_epoch2/closed_R`。正式指标来自对应 accepted 评测结果。二者均为 R 模式，使用各自闭环中实际记录的交通参与者，后续其他车辆反应不一定相同。

## 场景解读与限制

### 43 · 左转出口处的推进差异

两种模型前 2 秒的左转轨迹非常接近；后半段 Base 逐步降到约 1.0 m/s，SARA 沿左转出口多推进约 5.9 m，4 秒速度约 3.1 m/s。EP 0.695→0.966。这是本轮较值得先看的候选，但不能仅凭画面判断 Base 减速的内部原因；SARA 最后半秒也在减速，不能据此保证后续持续通行。

### 44 · 宽路口左转过程

两者都按左转方向行驶，SARA 在宽路口内完成更多转向与推进，四秒行程约 15.4→21.7 m。EP 0.919→1.000。场景转弯意图清楚、速度适中，但 Base 本身并没有明显失败，适合作为转弯推进的备选。

### 45 · 右转弯内的推进差异

两条路径几乎一致，SARA 在右弯内保留更多推进，四秒行程约 14.5→17.4 m，EP 0.643→0.772。它主要体现速度规划与推进差异，Base 减速也可能合理，因此优先级低，不建议写成“Base 错误决策”。

### 46 · 道路边缘附近的车道保持

桥面道路边缘附近，Base 后段更贴近地图边界，SARA 留在车道内。正式 DAC 0→1；辅助车身同向车道覆盖最低约 90.7%→100%，未检出普通对向车道重叠。等行程轨迹偏移最大约 0.44 m，差异较细，不能描述成明显冲出道路。Base 实际走了约 26.1 m，EP=0 不代表停车。

全部九个记录时刻均无采样回退、其他物体重叠或普通对向车道车身重叠。检查只覆盖 0–4 秒、0.5 秒离散采样，不涵盖未来行为或所有交通规则。地图车道覆盖是辅助诊断，不等同正式 DAC。路口连接线方向与 route ID 匹配也有局限。

这些片段可以展示奖励相关行为差异，但不能单凭个例证明奖励导致行为改变，或解释 Base 的内部决策原因。尤其 44/45 的 Base 减速本身不一定错误；46 的地图边缘差异较小。43 的 SARA 最后半秒也在减速，不能声称它在片段后必然持续正常通行。46 的 Base 实际行程约 26.1 m，正式 EP=0 不应解释为没有运动。
